API Reference

REST JSON

Base URL: http://localhost:8000

POST /detect/image
Upload image → JSON detections + annotated image (base64) 
curl -X POST "http://localhost:8000/detect/image" \
  -F "file=@traffic.jpg" \
  -F "confidence=0.4"
POST /detect/video
Upload video → annotated video file + statistics 
curl -X POST "http://localhost:8000/detect/video" \
  -F "file=@traffic.mp4" \
  -F "max_frames=150"
